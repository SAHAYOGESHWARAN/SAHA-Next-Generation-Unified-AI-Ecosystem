## 🧩 Component Architecture

### CyberCard Component
```tsx
<CyberCard glow={true} glowColor="cyan">
  {children}
</CyberCard>
```
**Features**: Corner decorations, glow effects, hover animations

### HolographicNode Component
```tsx
<HolographicNode
  icon={<Icon />}
  title="Title"
  color="cyan"
  size="md"
/>
```
**Features**: 3D appearance, rotating border, pulsing dots

### AnalyticsPanel Component
```tsx
<AnalyticsPanel
  title="Title"
  data={[{ label, value }]}
  color="cyan"
/>
```
**Features**: Animated bars, gradients, metrics

### NetworkViz Component
```tsx
<NetworkViz
  nodes={[{ id, label, x, y, size, color }]}
  title="Network"
/>
```
**Features**: Canvas rendering, dynamic connections, smooth animation
