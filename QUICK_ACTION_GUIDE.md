## 🐛 Troubleshooting

### Server won't start?
```bash
cd frontend
rm -rf node_modules .next
npm install
npm run dev
```

### Port 3000 already in use?
```bash
# Windows
netstat -ano | findstr :3000
taskkill /PID <PID> /F

# macOS/Linux
lsof -i :3000
kill -9 <PID>
```

### Need to rebuild?
```bash
cd frontend
npm run build
npm start
```
